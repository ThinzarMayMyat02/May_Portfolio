About

I’m May Myat Thinzar, a software engineer based in Myanmar.

I work on enterprise web applications using Java, Spring Boot, Angular and relational databases. My work spans application logic, user interfaces and the troubleshooting that connects them.

In team projects, I focus on my part of the application and work through how it fits with the rest of the system. When debugging, I trace the issue across application logic, database operations and deployment configuration to narrow down where it starts.

I studied Engineering Physics at Dagon University and completed the System Creator diploma at Metro IT Business College. Outside enterprise development, I explore lightweight web prototypes and AI-assisted document processing.
